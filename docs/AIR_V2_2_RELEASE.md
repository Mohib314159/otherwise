# Otherwise air / ULEZ v2.2 release

This release turns the air-pollution path into a defensible second signal family without changing the existing land-change method.

## Release protocol

`air-ground-no2-v2.2`

New protocol versions are included in run-ID hashing, so evidence generated by an older method is never silently reinterpreted under a newer method.

## Registered ULEZ cases

```bash
# primary known-answer validations
python -m scripts.run_air_case ulez-central-2019 --post-months 3
python -m scripts.run_air_case ulez-londonwide-2023 --post-months 3

# exploratory only; the evidence page is forced to CAN'T TELL
python -m scripts.run_air_case ulez-inner-2021 --post-months 3

# reveal published comparisons only after Otherwise has run
python -m scripts.air_known_answers
```

2019 uses a post-T-Charge baseline beginning 2018-03-08. 2023 uses a post-COVID baseline beginning 2021-07-19 and treats newly covered outer London (London-wide/LEZ footprint minus the 2021 ULEZ polygon), not all London.

## Repeatable validation

```bash
python -m scripts.air_redteam
python -m scripts.air_power --seeds 10 --effect -6
pytest -q tests/test_air_analysis.py tests/test_air_cases.py tests/test_air_providers.py \
  tests/test_air_run_hardening.py tests/test_air_server.py tests/test_air_report.py
```

See `docs/AIR_METHOD.md` for the method and `docs/AIR_REDTEAM_REPORT.md` for adversarial results and remaining identification limits.

## Data providers

- LAQN / Imperial ERG: treated London NO₂ monitors
- DEFRA AURN: non-London UK controls
- ERA5 via Open-Meteo historical API: meteorological adjustment
- GLA/TfL ArcGIS: official ULEZ/LEZ geometries

HTTP responses are cached under `APP_AIR_CACHE_DIR` (default `data/air_cache`). Missing/invalid observations and excluded event-crossing bins produce receipts rather than being silently coerced.

## Deployment

The Docker image sets persistent-style runtime locations under `/data`:

- `APP_RUNS_DIR=/data/runs`
- `APP_CACHE_DIR=/data/cache`
- `APP_AIR_CACHE_DIR=/data/air_cache`

On hosts with ephemeral disks these caches/results remain ephemeral unless a persistent volume is mounted; permalink semantics still remain immutable because the method version is in the run ID.
